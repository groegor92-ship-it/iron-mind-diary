IRON MIND 2.0 — УСТАНОВКА НА SAMSUNG GALAXY S23

Вариант 1: открыть автономный файл
- Скачайте IRON_MIND_2_0.html и откройте его на телефоне в браузере.
- Интернет для вычислений не требуется.
- Некоторые версии Android/Chrome ограничивают открытие локальных HTML-файлов или хранение данных для file://.
- Для надёжного значка на главном экране и постоянного адреса используйте вариант 2.

Вариант 2: установить как веб-приложение (PWA)
1. Распакуйте архив IRON_MIND_2_0_PWA.zip.
2. Разместите файлы из папки iron_mind_2_pwa в корне HTTPS-сайта; например, GitHub Pages или другой статический хостинг. Обязательно нужны index.html, manifest.webmanifest, sw.js и иконки.
3. Откройте URL опубликованного сайта в Chrome на Samsung Galaxy S23.
4. Нажмите меню Chrome (три точки) -> «Добавить на главный экран» / «Установить приложение» (вариант зависит от версии).
5. Откройте значок IRON MIND на главном экране.
6. После первой загрузки на HTTPS-сайте приложение кэширует файлы для офлайн-работы. Проверьте запуск в авиарежиме.

ХРАНЕНИЕ
- Записи автоматически сохраняются локально в хранилище браузера для конкретного адреса сайта.
- Нет облачной синхронизации: данные не переносятся при смене адреса или устройства.
- Регулярно используйте «Архив» -> «Скачать JSON» и храните файл в другом месте.
- Для восстановления: «Архив» -> выберите JSON -> «Восстановить из файла».
- Импорт полностью ЗАМЕНЯЕТ текущий журнал, сначала сделайте его копию.

ФОРМУЛЫ
- Повторения: сумма фактических значений всех подходов (5×15 = 75; 12+3 = 15).
- Время упражнений с повторениями: общее число повторений × темп (сек/повтор) + (подходы − 1) × отдых.
- Время удержаний: сумма секунд + отдых между подходами.
- Для бега/дистанции время не рассчитывается.
- Общий итог не включает разминку, переходы, заминку и другие упражнения, пока вы их не добавите.

Важно: файл не передаёт ваши записи на сервер. При удалении данных сайта, инкогнито или смене устройства записи могут пропасть без JSON-копии.
